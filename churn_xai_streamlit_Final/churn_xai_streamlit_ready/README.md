# 📉 Customer Churn Prediction using Streamlit

This is a simple ML-based web app to predict whether a customer will churn, based on their behavior and service details.

## 🛠 Built With
- Streamlit
- Scikit-learn
- Pandas
- SHAP & LIME for XAI
- Pre-trained RandomForest model

## 🚀 How to Use
1. Upload a CSV file with customer data
2. The app will return churn predictions and probabilities

## 🧪 Input Format
The uploaded file should include all required features used during training.
